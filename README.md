# Bayesian inference of cell-division rules

This is the official repository for the paper [**_Nonlinear memory in cell division dynamics across species_**](https://arxiv.org/abs/2408.14564).

Here, we implement and apply a framework that makes it possible to infer stochastic differential equation (SDE) models with Poisson noise directly from experimentally measured time series for cellular growth and divisions.

### Experimental data
The experimental data we analyzed in this paper are from the following published work:

##### *E. coli*
P Wang, et al., [Robust growth of Escherichia coli.](https://doi.org/10.1016/j.cub.2010.04.045
) Curr. Biol. 20, 1099–1103 (2010). [[Dataset](https://jun.ucsd.edu/files/mothermachine/complete%20data%20Curr%20Biol%2020,%201099-1103%20(2010).zip)]

##### *S. pombe*
H Nakaoka, Y Wakamoto, [Aging, mortality, and the fast growth trade-off of Schizosaccharomyces pombe](https://doi.org/10.1371/journal.pbio.2001109
). PLoS Biol. 15, e2001109 (2017). [[Dataset](https://datadryad.org/dataset/doi:10.5061/dryad.s2t5t)]

##### *Dictyostelium*
M Tanaka, T Kitanishi-Yumura, S Yumura, [A ‘dynamic adder model’ for cell size homeostasis in Dictyostelium cells](https://doi.org/10.1038/s41598-021-92700-3
). Sci. Rep. 11, 13742 (2021). Data shared by Prof. Shigehiko Yumura.

##### *B. subtilis*
N Nordholt, JH van Heerden, FJ Bruggeman, [Biphasic cell-size and growth-rate homeostasis by single Bacillus subtilis cells](https://doi.org/10.1016/j.cub.2020.04.030). Curr. Biol. 30, 2238–2247 (2020). Data shared by Prof. Frank J. Bruggeman.
